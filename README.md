
# My First Flask Application

## Project Description
This is a simple web application developed using Python and Flask.
It contains Home and About pages.

## Technologies Used
- Python
- Flask
- HTML
- VS Code

## Project Structure
my_flask_app/
│
├── app.py
├── requirements.txt
└── README.md

## Installation

1. Clone the repository:

   git clone https://github.com/username/my_flask_app.git

2. Open the project folder:

   cd my_flask_app

3. Install the required packages:

   pip install -r requirements.txt

## Run the Application

python app.py

## Application URLs

- Home: http://127.0.0.1:5000/
- About: http://127.0.0.1:5000/about

## Features
- Simple Flask application
- Home page
- About page
- Local development server
